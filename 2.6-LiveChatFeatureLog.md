# 2.6 LiveChat App w/ Cross-Platform Sync

## Notes on Implementation

This project was built for Assignment 2.6 – Queued Offline Messages.
Some parts of the code (such as the socket service, offline queue handling, and other supporting files) were adapted or edited with the help of AI-assisted code generation. I then reviewed, tested, and modified the code to ensure it worked correctly for my setup (LAN IP, server config, and React Native client).

### Key things I learned and implemented:

- Detecting when the client is offline vs online
- Queueing messages locally while offline
- Automatically sending queued messages once the connection is restored
- Using socket.io events to sync state between client and server
- Organizing files into a clean structure for easier development
- Converting styling over to React Native StyleSheet instead of NativeWind

This repo demonstrates that the app continues to work even if Wi-Fi is disabled and later reconnected.

## Testing / Demo

To confirm my implementation worked, I tested it step by step:

1. Opened the app while connected to Wi-Fi.
2. Sent a few normal messages (delivered immediately).
3. Disabled Wi-Fi -> sent additional messages (they were stored in the offline queue).
4. Re-enabled Wi-Fi -> queued messages were automatically delivered to the server and synced across clients.

✅ The chat continued to work even after going offline and reconnecting, proving that the offline queueing logic functioned as expected.
